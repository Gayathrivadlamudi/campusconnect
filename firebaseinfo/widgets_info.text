| Symbol   | Meaning              |
| -------- | -------------------- |
| `^`      | Start of string (start checking from the string ^abc |
| `$`      | End of string        |
| `+`      | One or more          |
| `.`      | Any character        |
| `\.`     | Actual dot `.`       |
| `@`      | Literal `@`          |
| `[]`     | Character set   Match one character from a particular set.[abc]  a OR b OR c|
| `[^...]` | NOT these characters [^@\s]|
| `\s`     | Whitespace           |

if (!mounted) return;
mounted is a property in state class
if mounted is true the screen is still attached to widget tree if false it is removed from widget tree
Step 1: User taps Sign In
Firebase starts checking the email and password.
Step 2: User leaves the screen
For example, they navigate to another screen while Firebase is still processing.
Step 3: Firebase finishes
The original login screen may now have mounted == false.
Step 4: The check runs
if (!mounted) return; stops the method before it tries to update the old screen.

if we dont keep this  suppose when firebase finishes ,the code contines and calls setstate() on
disposed widget(means the screen is removed from the widget tree)
Flutter can report an error similar to:setState() called after dispose()
This is because the screen has already been removed, but the asynchronous method is still running.
