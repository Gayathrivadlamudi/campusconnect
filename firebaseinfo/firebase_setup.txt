first create an project in firebase with same package that we created the flutter
add firebase_core plugin  to intialize the firebase


install Firebase CLI
npm install -g firebase-tools
After installation, you get a command called:
firebase
firebase login ""Log my Google/Firebase account into the command line.""
firebase projects:list "to see Firebase projects you have access to."
Firebase CLI = general tool for working with Firebase from your terminal.


now we need to install flutterfire cli
dart pub global activate flutterfire_cli (to help configure Firebase with Flutter.
we need to add path
You can also open it directly:
explorer "%LOCALAPPDATA%\Pub\Cache\bin"
If you see flutterfire.bat, copy the path and add to enviromnet varaible
flutterfire configure then run this in terminal

after configuring firebase_option.dart file will be generated(This is a Dart file generated by FlutterFire.)
"firebase_options.dart contains the configuration details for connecting our Flutter app
to the Firebase project for each platform, such as Android, iOS, or Web."

Now we have firebase_options.dart
But Firebase still needs to be initialized when your app starts.
but before intilizing firebase we need flutter binding
No work before runApp()
        ↓
   runApp()
        ↓
Binding initialized
        ↓
      UI


Work before runApp()
        ↓
ensureInitialized()
        ↓
Binding initialized
        ↓
Firebase / platform initialization
        ↓
runApp()
        ↓
      UI

Normally flutter app starts with runapp() this starts preparing flutter framework and connects
dart code with platform so
main()
  ↓
runApp()
  ↓
Flutter framework starts
  ↓
Your UI appears

but when we need to intlize firebase first before runapp
we are asking flutter to perfomr framework.platform relaed operating before actual framwork starts
That's why we put:

WidgetsFlutterBinding.ensureInitialized(); Make sure Flutter's binding has been initialized before we continue."

 await Firebase.initializeApp(
