handling api error is also an imp thing

1)no internet connection
2)server may be down
3)api returning error codes 400,401
4)request takes too long
5)json parsing

using try catch we can handle the erros that occur while making a request to api
try {
  final response = await http.get(url);

  if (response.statusCode == 200) {
    print(response.body);
  } else {
    print('Request failed: ${response.statusCode}');
  }
}
catch (e) {
  print('Error: $e');
}
try → executes code that may cause an error.
catch → catches an exception if one occurs.
statusCode → checks the HTTP response returned by the server.

if request is taking to much of time we use timeout method

try {
  final response = await http.get(url).timeout(
    const Duration(seconds: 10),
  );
}
on TimeoutException {
  print('Request timed out');
}
catch (e) {
  print('Something went wrong: $e');
}
