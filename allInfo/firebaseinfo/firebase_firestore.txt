When you use Firebase Authentication and Firestore together in your Flutter app, the authentication information
is attached automatically to Firestore requests.
You don't need to manually send Ravi's UID or token with every request.

Suppose Ravi signs in:
await FirebaseAuth.instance.signInWithEmailAndPassword(
  email: email,
  password: password,
);Firebase Authentication identifies Ravi and maintains his signed-in session.

Then Ravi requests hackathons:

final snapshot = await FirebaseFirestore.instance
    .collection('hackathons')
    .get();

    Behind the scenes:
    1. Flutter sends a request to Firestore.
    2. Firebase's SDK automatically includes the authentication information for the current signed-in user.
    3. Firestore evaluates the security rules.
    4. If the rules allow Ravi to read the data, Firestore returns it. Otherwise, the request is denied.
