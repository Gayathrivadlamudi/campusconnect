try: Contains the code that might produce an error.
catch: Handles the error if one occurs.
finally: Executes whether an error occurs or not.
One additional point: We can also use on to catch a specific exception type.
that is if we want to use specific exception type we use this
try {
  // Risky operation
} on FirebaseException catch (e) {
  print(e.message);
} catch (e) {
  print("Something went wrong: $e");
} finally {
  print("Completed");
}
