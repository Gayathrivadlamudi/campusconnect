responsive ui means the application ui should adjusts to differnet screen sizes
1)mediaquery: mediaquery is widget that give info about screen size such as width, height.
final width = MediaQuery.of(context).size.width;
final height = MediaQuery.of(context).size.height;

MediaQuery tells us how big the screen is,
 whereas LayoutBuilder tells us how much space is available to a particular widget from its parent.
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth >= 500) {
      return Row(
        children: [
          Container(width: 250, height: 100),
          Container(width: 250, height: 100),
        ],
      );
    }

    return Column(
      children: [
        Container(width: 250, height: 100),
        Container(width: 250, height: 100),
      ],
    );
  },
)

Expanded:it makes the child of row,colun,flexible occupy the available remaing space
Row(
  children: [
    Expanded(
      child: Container(color: Colors.blue, height: 100),
    ),
    Expanded(
      child: Container(color: Colors.red, height: 100),
    ),
  ],
)

4. Flexible
Flexible allows a child to occupy available space but doesn't force it to fill all that space.

Difference:
- Expanded forces the child to fill its allocated space.
- Flexible allows the child to use less than its allocated space.

InheritedWidget helps share data with descendant widgets without passing it manually through every widget constructor.

of(context)	Gets the inherited data
Theme.of(context) allows child widgets to access the application's theme without manually passing theme data
through every widget.

"InheritedWidget is used to share data across multiple descendant widgets without passing it through every constructor. It helps avoid prop drilling.
For example, we can share theme information or user details with multiple child widgets."

"initState() is a inbuilt method of StatefulWidget that is called only once when the State object is created.
 We use it to initialize variables, controllers and fetch initial data when the screen loads."

 dispose(): it is triggered only once when the widget is removed from the widget tree
  Its primary function is to release memory allocated to controllers, streams, and timers,

 "setState() is a method used in StatefulWidget to notify Flutter that the state has changed.
 Flutter then rebuilds the widget to reflect the updated data in the UI."

 setState()
 - Used in StatefulWidget.
 - When we call setState(), Flutter schedules a rebuild of that State object's widget subtree.
 - We manually tell Flutter when the state changes.

 GetX (.obs and Obx)
 - .obs makes a variable observable.
 - Obx() listens to the observable variable.
 - Whenever the observed value changes, Obx() automatically rebuilds its widget.
